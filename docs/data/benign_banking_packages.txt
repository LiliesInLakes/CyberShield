# Benign Indian banking / UPI / finance app package names.
#
# Unlike a trojan's package (attacker-chosen, unverifiable, T8), these are the
# PUBLIC, stable Google Play package ids of legitimate apps — each maps to a
# real Play listing and can be cited. Used with:
#
#   androzoo_fetch.py --index --min-vt 0 --max-vt 0 \
#       --pkg-exact-file docs/data/benign_banking_packages.txt \
#       --market-substr play.google.com --per-pkg-cap 3
#
# The --max-vt 0 filter keeps only VirusTotal-clean builds, so this is a genuine
# benign hard-negative panel (T27) — the class the F-Droid corpus entirely lacks
# and the reason the unified model's AUROC is currently a source-confound upper
# bound. A name not present in AndroZoo simply yields nothing (safe).
